# Data_Analysis
# 📊 Sales Data Analysis Tool

This project is a Python script designed to analyze sales data from CSV files. It performs data cleaning, transformation, and generates useful business insights such as revenue, top products, and grouped summaries.

---

## 🚀 Features

- 📂 Load CSV data easily
- 🧹 Clean dataset (remove duplicates, handle missing values)
- 🔢 Convert data types automatically
- ➕ Generate calculated fields like Revenue
- 📊 Summary statistics for analysis
- 📦 Group-wise analysis (Category/Product)
- 💡 Key business insights extraction
- 📈 Optional data visualization using Matplotlib

---

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Argparse (for command-line usage)
